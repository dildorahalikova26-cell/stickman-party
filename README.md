# 🎮 Stickman Party - 30 Mini Games

Uzbekistonda birinchi "Stickman Party" o'yini!

## 🎯 O'yin Xususiyatlari

- ⚽ **Futbol** - Insan vs Robot
- 🎯 **Strelka** - Insan vs Robot  
- 🏃 **Coraja** - Tezlik testi
- ⚡ **Tezlik** - Tezburchililik
- 🥊 **Boks** - Insan vs Robot
- 🏀 **Basketbol** - Bola otish

## 📱 Platformalar

- ✅ **Telefon** (iOS/Android)
- ✅ **Desktop/Laptop**
- ✅ **Tablet**

## 🚀 Qanday Ishlash

1. `index.html` faylni brauzerda oching
2. O'yin tanlang
3. O'ynang va yutuq qoling! 🎉

## 🏆 Ranking

Har bir o'yin tugaganidan keyin sizning skoringiz Top 5'da saqlanadi.

## 💾 Ma'lumot Saqlash

Barcha skorlar `LocalStorage`'da saqlanadi - internetsiz ham ishlaydi!
